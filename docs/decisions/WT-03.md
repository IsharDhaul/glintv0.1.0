# WT-03 decisions

- 2026-10-29: Normalization parameters (duration bounds, accepted forms, TTM/FY tolerance, quarter contiguity, year-ago window, series lengths) live in `config/concepts.yaml` (`durations`, `forms`, `normalize`) rather than `thresholds.yaml` — WT-03 owns `concepts.yaml`; `thresholds.yaml` is WT-06's.
- 2026-10-29: Duration bounds kept exactly as §4.3 rule 2 (80–100 / 170–190 / 260–285 / 350–380 days, length = end − start).
- 2026-10-29: Facts are read only from periodic reports, their amendments and 8-K/6-K (`forms` in `concepts.yaml`). DEF 14A is excluded: pay-versus-performance tables reuse `NetIncomeLoss` etc., and as the latest filing it would win "latest filed" and point `source_accn` at a proxy.
- 2026-10-29: `eps_diluted` and `diluted_shares` are `additive: false` — EPS and weighted share counts don't subtract (Q4 ≠ FY − 9M), so they get quarters only from filed 3-month facts and never a summed TTM.
- 2026-10-29: A `(taxonomy, tag)` may belong to only one line item (the loader rejects duplicates), so a fact maps to exactly one line item.
- 2026-10-29: `debt_current` — `DebtCurrent` is a total and wins; otherwise the value is the sum of two distinct components, `current_ltd` (`LongTermDebtCurrent`) + `short_term` (`ShortTermBorrowings`, else `CommercialPaper`), flagged derived. CP is used only without STB because filers often report CP inside short-term borrowings (no double count). Configured as `sum_groups`; every tag stays under `tags` so extraction and fixture trimming still keep it.
- 2026-10-29: `debt_noncurrent` marks `LongTermDebt` as `includes_current` (§4.3 rule 9), consumed by the `total_debt` rule.
- 2026-10-29: `not_applicable: [Banks, Insurance, Capital Markets]` on cost_of_revenue, gross_profit, current_assets, current_liabilities, inventory — a missing value there is reported as NOT_APPLICABLE_SECTOR (n/m by design), not MISSING_INPUT (§4.5).
- 2026-10-29: Dedupe key is (period, tag): the latest `filed` wins (ties broken by accession, then value, so results are deterministic); the earliest `filed` is `first_filed_*`. Precedence then runs per period across tags.
- 2026-10-29: A company's taxonomy is whichever of us-gaap/ifrs-full has more mapped facts (ties → us-gaap); facts from the other taxonomy are dropped (dei cover tags always kept).
- 2026-10-29: Monetary facts in any currency other than the reporting currency are rejected as a unit mismatch (TSM files USD convenience translations next to TWD). If a company has no revenue facts, the reporting currency falls back to the most common currency across all mapped monetary facts.
- 2026-10-29: A value built from `sum_groups` components is `derived=true` with `source_tag=null` (per the `financials` DDL); the component tags are kept in memory (`Value.inputs`) for `glint financials --sources`. Its `first_filed_value` is the sum of the components' first values, dated by the latest of them.
- 2026-10-29: Fiscal years are identified by duration only (350–380 days), with no check against annual forms — across all fixtures every 12-month period comes from a 10-K/20-F except KHC's 2012 Heinz-predecessor 8-K. When two FY periods share an end, the latest filed wins.
- 2026-10-29: Discrete quarters generalise rule 5: a quarter ending at a YTD end is that YTD minus the latest earlier cut-off with the same start, where the earlier cumulative is the filed YTD value or, if none was filed, the sum of the contiguous discrete quarters it covers (same arithmetic, more coverage). A remainder that isn't quarter-length is never used.
- 2026-10-29: Two flags on a value: `derived` (a rule-9 derivation or sum-group components → DERIVED_INPUT) and `quarter_derived` (§4.3 rule 5). `financials.derived` = `derived OR quarter_derived` on `q` rows, and `derived` alone on `fy`/`ttm`/instant rows — a TTM that includes FY − 9M is the TTM definition working, not a derived input.
- 2026-10-29: Quarter contiguity is exact (next start = previous end + 1 day, `quarter_gap_days: 1`); the 4-quarter span must also classify as a fiscal year (350–380 days). No slack needed on AAPL/MSFT/KO/NVDA.
- 2026-10-29: At a fiscal year end TTM = FY (source tag and accession of the FY fact); elsewhere TTM is the 4-quarter sum with `source_tag=null` and `derived` = any quarter carrying a derived input. A failed FY consistency check is a warning, not a null: in the fixtures it fires only for restated years (MSFT FY2016 ASC 606 restatement, KO 2018), where the restated FY is the better number.
- 2026-10-29: Instants are written under two bases: `mrq` = every balance-sheet date (latest 12; MRQ is the max `period_end`, year-ago is looked up within ±45 days of the same calendar day a year earlier, ties → the earlier date), and `fy` = the instants dated exactly on a fiscal year end (latest 10). Flows: `fy` (10), `q` (12), `ttm` (12). Counts live in `concepts.yaml` `normalize.keep`.
- 2026-10-29: Derivations run per exact `(start, end)` on the selected values, before quarters and TTM, so a derived FY and its derived 9M split into a consistent Q4. A derivation fills only periods with no tagged value where every input has that same period; inputs are recorded (`+ revenue (Tag)` …).
- 2026-10-29: total_debt as implemented — if debt_noncurrent comes from `LongTermDebt` (includes the current portion): `LongTermDebt` + the `short_term` component (ShortTermBorrowings, else CommercialPaper) only, ignoring `DebtCurrent`/`LongTermDebtCurrent` (they would double count current maturities); otherwise debt_current + debt_noncurrent. Whichever parts are tagged are summed; with none, no value (never a zero fill). Operating leases excluded.
- 2026-10-29: Derivation graph is validated as acyclic at load time (ContractError on a cycle) and evaluated in topological order.
- 2026-10-29: Share count (rule 11): per date dei cover value beats `CommonStockSharesOutstanding`; the latest date wins (cover dates follow the balance sheet, so dei normally wins). If that count is older than the latest diluted weighted-average count by > `shares_stale_days` (365), or missing, the diluted count is used, `derived=true`, dated at its period end. `shares_as_of` = the chosen count's date. Ford (no single cover total since 2011) falls back; BRK (no diluted count either) keeps its 2011 count with a stale-shares warning — multi-class handling is `share_classes.yaml` (WT-01/06).
- 2026-10-29: FY changes (rule 14) are detected from (a) a 10-KT whose own latest period isn't fiscal-year length, and (b) consecutive fiscal years whose ends differ on the calendar by > `fy_change_shift_days` (10; 52/53-week drift is ≤ 7). Breaks = the old year end and the transition end; no summed TTM may span either, so TTM resumes at the first new FY. ANAB (Dec → June, 10-KT for Jan–Jun 2026) is the fixture case.
